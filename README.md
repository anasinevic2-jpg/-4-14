# -4-14
синевич анна лаборатарорная 4 вариант 14
Задание 1
Ввести n (1..31) и n целых температур (−40..50). В цикле for найти среднюю температуру, число морозных дней (температура ниже 0) и самую длинную подряд идущую серию морозных дней. Вывести её длину и первый день серии; если серии нет — 0 и 0. При одинаковой длине оставить самую раннюю.

Задание 2
Ввести два натуральных числа a и b (1..1 000 000). С помощью while найти их наибольший общий делитель алгоритмом Евклида: повторять замену (a, b) на (b, a % b), пока b не станет 0. Вывести НОД и количество выполненных замен.

Задание 3
Через do-while вводить целые температуры (−20..40) до появления трёх подряд значений строго выше 20. Недопустимые температуры игнорировать и не прерывать серию корректных значений; значения от −20 до 20 включительно обнуляют текущую серию. Вывести число принятых измерений и количество всех значений выше 20.

Задание 4
Ввести базовую температуру B (−10..20). Вложенными циклами построить сетку из 7 дней (строки) и 6 интервалов (столбцы). Температура в ячейке (i,j) равна B + i − 2·j. Печатать «−» при отрицательной температуре, «0» при нулевой и «+» при положительной. Вывести количество положительных ячеек.
